# Workflow
- One phase only (blueprint Part 7). Stop when its Done criteria pass; never start the next phase.
- Before coding, read the blueprint sections for the phase and write a short plan.
- Do not modify earlier-phase code without telling the user first.
- Quote every (verify) item back to the user; list them in VERIFY.md. Flag anything recalled from memory.
- No new dependencies beyond blueprint Part 11 without asking.
- End each phase with: commands run, pass/fail counts, tolerances chosen and why, open doubts.
- No CUDA GPU: do code and CPU tests only, say so, never fake training results.
